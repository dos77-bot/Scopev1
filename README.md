# Scopev1 – Sniper Scope

**100-Level Finger-Swipe Sniper Game for Android / Samsung**

A complete, offline-playable HTML5 sniper game designed for mobile.

## Features

- **Finger swipe** to aim the scope
- **Hold to zoom**, **release to fire**
- **Headshot-only** stick-figure targets (headset area is the only valid hit zone)
- **100 levels** with progressive difficulty
- **Puzzles**: shoot ropes and locks to reveal hidden targets
- **Limited ammo** + **Easy Mode** (unlimited ammo)
- **Reload** and **Zoom toggle** buttons
- Fully **offline** after first open
- **PWA-ready** (Add to Home Screen on Samsung/Android)
- Official neon hot-pink theme with stick-figure-in-crosshairs icon

## How to Play

1. Download `sniper-scope-game.html`
2. Open it in Chrome or Samsung Internet
3. Tap **START MISSION**
4. Optional: Add to Home Screen for fullscreen app experience

## Controls

- Swipe finger to aim
- Hold screen → zoom in / steady
- Release → fire
- **RELOAD** button
- **ZOOM** button (cycles x1 / x2 / x3)
- **EASY** toggle for unlimited ammo
